INSTALL / CONTRIBUTE

三步换一种
桌面空气。

  1. 01

    下载收藏

    下载 deskbox-themes 分支 ZIP，解压后选中一个主题文件夹。

  2. 02

    放入主题目录

    在“设置 › 外观”点击“打开主题文件夹”，复制完整主题文件夹。

  3. 03

    扫描并切换

    点击“重新扫描主题”，从同一页的预览列表中选择并立即切换。

下载主题收藏 提交你的主题

目前主题需要支持 schema v1 的 DeskBox Themes 开发分支。官方 DeskBox 尚不能直接安装这些主题。

# DeskBox Themes

**让桌面拥有你的风格。**

[English](README.md) | 简体中文

基于 [DeskBox](https://github.com/Tianyu199509/DeskBox) 的开放主题社区。从烟熏玻璃到雾凇，探索桌面外观、分享原创设计，一起建设 Windows 桌面主题生态。

> **开发初期。** 本仓库当前包含上游应用源码和社区文档。两个主题已有本地源码原型，尚未迁入此仓库。外部主题加载、可下载主题包和主题市场网站均未上线。

## 首批主题

| 主题 | 设计方向 | 当前状态 |
| --- | --- | --- |
| **烟熏玻璃 · Smoke Glass** | 深色半透明、青紫光边、多层高光、凸起控件 | 本地源码原型，待迁移 |
| **雾凇 · Alpine Mist** | 浅色磨砂、冰蓝卡片、柔和阴影与层次 | 本地源码原型，待迁移 |

[主题目录](themes/README.md)介绍当前系列及投稿要求。实机截图将在迁移验证后补充；设计参考图不会作为产品截图展示。

## 兼容说明

这些主题将需要搭配**支持主题加载的 DeskBox 版本**使用。把文件复制到未经改造的官方版目录，并不能启用本项目规划的主题系统。

本仓库继承上游 1.5.0 发布提交，本地主题实验基于 1.4.9，需要迁移和测试。现在编译本仓库，**还不会得到玻璃和雾凇主题**。

计划采用纯数据与素材的主题格式。接口版本管理、默认值和兼容回退属于待实现能力，暂不承诺任意版本都兼容。

## 参与社区

欢迎贡献主题创意、原创素材、文档和兼容反馈。阅读[投稿指南](CONTRIBUTING.md)，通过 Pull Request 向**本仓库**投稿。我们的主题社区投稿规则与原作者仓库的贡献规则相互独立。

初期通过 GitHub PR 审核收录主题，之后再建设网页市场和应用内安装入口。

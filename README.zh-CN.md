# DeskBox Themes

**让桌面拥有你的风格。**

[English](README.md) | 简体中文

基于 [DeskBox](https://github.com/Tianyu199509/DeskBox) 的开放主题社区。从烟熏玻璃到雾凇，探索桌面外观、分享原创设计，一起建设 Windows 桌面主题生态。

> **开发初期。** schema v1 加载器、烟熏玻璃与雾凇主题文件夹已进入 `deskbox-themes`
> 分支；小组件和搜索窗口正在进行宿主视觉联调，当前尚未发布面向普通用户的安装包。

## 首批主题

| 主题 | 设计方向 | 当前状态 |
| --- | --- | --- |
| **烟熏玻璃 · Smoke Glass** | 深色半透明、青紫光边、多层高光、凸起控件 | schema v1 主题，宿主联调中 |
| **雾凇 · Alpine Mist** | 浅色磨砂、冰蓝卡片、柔和阴影与层次 | schema v1 主题，宿主联调中 |

## 兼容说明

这些主题将需要搭配**支持主题加载的 DeskBox 版本**使用。把文件复制到未经改造的官方版目录，并不能启用本项目规划的主题系统。

本仓库继承上游 1.5.0 发布提交。当前开发分支已经包含主题引擎和两个内置主题，但仍需完成更多实机与兼容性测试。

主题采用纯数据与安全预览素材，不包含 DLL、脚本或任意 XAML。schema 版本、最低宿主版本检查和 Classic 回退已经实现，但仍不承诺跨任意版本兼容。

## 参与社区

欢迎贡献主题创意、原创素材、文档和兼容反馈。阅读[投稿指南](CONTRIBUTING.md)，通过 Pull Request 向**本仓库**投稿。我们的主题社区投稿规则与原作者仓库的贡献规则相互独立。

初期通过 GitHub PR 审核收录主题。双语[主题广场](docs/index.html)已经可以浏览首发收藏；应用内在线安装仍属于后续能力。
